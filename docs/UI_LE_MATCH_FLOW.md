# Le Match — tableau d'affichage et cinq indices

Statut : **intégré dans `index.html`** le 2 octobre 2026, à vérifier sur un vrai téléphone et en partie. La [planche initiale](ui/26-le-match-evenement-3.jpg) et le [pack séparé](../assets/ui/le-match/README.md) restent la référence pour l'ambiance bleu nuit du tableau d'affichage. La chronologie d'événements visible sur cette ancienne planche n'est plus la règle du jeu.

La carte centrale affiche « Le Match », `? VS ?` et cinq rangées de hauteur fixe. **Aucune compétition n'apparaît avant le dernier indice.** La rangée courante est éclairée avec son palier ; les indices précédents restent visibles ; les suivants montrent « Indice à venir ». Les cinq rangées sont toujours, dans cet ordre : **score final (5 pts), ville (4 pts), phase de la compétition (3 pts), année (2 pts), compétition (1 pt)**. La ville désigne le lieu du match, pas le nom de l'enceinte. La phase peut être un tour de coupe ou une journée de championnat.

Les deux équipes restent cachées jusqu'à une bonne réponse ou à la fin de la carte ; elles remplacent alors `? VS ?` en texte. L'en-tête, les scores, le chrono, le bouton Tackle, les commandes RÉPONDRE / PASSER et le verdict restent les composants communs. Le délai de 30 secondes de priorité puis 5 secondes de course recommence à chaque indice. Les points, la pénalité de mauvaise réponse et le Tackle suivent les règles de [`GAME_DESIGN.md`](GAME_DESIGN.md).

Les 203 cartes et les liens qui sourcent leur ville se trouvent dans `src/data/lematch-cards.json`. Les anciens événements des 103 premières cartes y restent archivés, sans être affichés. La [relecture initiale](LE_MATCH_CARDS_REVIEW.md) décrit cette ancienne version ; les [100 nouvelles cartes](LE_MATCH_100_HISTORIC_CARDS.md) sont listées séparément.
